# Contributing

Keep this repository a static, reusable LGU website template. Use literal `<placeholder>` values for unverified local content and render them as text. Update all supported translations when editing visible text. Never commit credentials, tracking IDs, personal contact details or local datasets into the base template.

Run `npm run audit:template`, `npm run build` and the relevant browser tests before submitting a change. See README.md for setup and customization guidance. Preserve the attribution notices in LICENSE.
